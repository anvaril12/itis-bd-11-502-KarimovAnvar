# itis-bd-11-502-KarimovAnvar

Название проекта: MultiGarage - учет личного транспорта.

Это система для учета личного транспорта: велосипед, машина, мотоцикл, самолет, лодка. Вместо 5 Excel таблиц, все ТС и их характеристики будут хранится в одной базе данных с возможностью фильтрации, поиска и контроля принадлежности.
